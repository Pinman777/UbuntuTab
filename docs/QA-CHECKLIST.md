# UbuntuTab — QA-чеклист приёмки (MVP)

Из спека `docs/FORK-ARCHITECTURE.md` §5. Заполняется на живых устройствах: Huawei MatePad 11.5"S (HarmonyOS 4.2) и Infinix Note 30 (XOS 13).

## Сборка

- [ ] `cd app && flutter build apk --release` — exit 0, APK собран
- [ ] APK устанавливается на обоих устройствах (sideload)

## Установка (первый запуск)

- [ ] Welcome-экран → кнопка «Install Ubuntu» → запуск единого флоу (без выбора DE/root-диалогов)
- [ ] Чеклист проходит по шагам: Bootstrap → Образ Ubuntu 24.04 → apt-пакеты → XFCE → QwenPaw → Finalize
- [ ] Лог установки читается, кириллических квадратов нет
- [ ] По завершении — «Setup Complete», кнопка «Launch UbuntuTab» ведёт на home

## Сессия

- [ ] «Open Ubuntu» → XFCE-сессия **≤ 60 с** от тапа (холодный старт; замерить: ___ с)
- [ ] Повторный вход (сессия уже запускалась) — ≤ 30 с: ___ с
- [ ] Клавиатура/мышь (BT и/или USB-C) работают в сессии

## Внутри Ubuntu

- [ ] `sudo apt update && sudo apt install <pkg>` — работает
- [ ] Firefox ESR открывается, рендерит страницы
- [ ] Кириллица: ввод и отображение в терминале и Firefox
- [ ] Ярлык «QwenPaw Console» в меню; `qwenpaw --version` отвечает в venv
- [ ] Menu-sync: ≥ 5 ярлыков из Ubuntu видны в лаунчере UbuntuTab

## Стабильность

- [ ] Сессия живёт 10 минут при выключенном экране (wake lock держит)
- [ ] Сворачивание/разворачивание приложения не убивает X-сессию
- [ ] Долгая установка (15 мин) не прерывается убийством фона (XOS!)
- [ ] Память: XFCE + Firefox < 5.5 ГБ RSS (8 ГБ устройство): ___ ГБ

## Известные нефичи (не баги)

- snap-пакеты не работают (нет snapd в proot)
- 3D/тяжёлый GPU-софт медленный на Maleoon/Mali (llvmpipe)
- Docker не работает (андроидное ядро без нужных cgroup/namespace-прав)
